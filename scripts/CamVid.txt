
CamVid setup

1. Config

In config/config.py:

dataset_name = "camvid"
camvid_root = PROJECT_ROOT / "data" / "CamVid"
use_dataset_profile = True

2. Detected local CamVid structure

images:
- data/CamVid/train
- data/CamVid/val
- data/CamVid/test

masks:
- data/CamVid/trainannot
- data/CamVid/valannot
- data/CamVid/testannot

palette file:
- data/CamVid/class_palette.csv

mask naming:
- image: 0016E5_07959.png
- mask: 0016E5_07959_L.png

3. Current code support

CamVidDataset now supports:
- train/trainannot/val/valannot/test/testannot
- class_palette.csv and class_dict.csv
- mask suffixes like _L

4. Run commands

teacher:
python -m scripts.train

mobile:
python -m scripts.train_mobile

5. Notes

- When dataset_name = "camvid", the dataset profile sets:
  - num_classes = 11
  - crop_h = 360
  - crop_w = 480
- train.py / train_mobile.py / tst_dataset.py all use the same dataset switch from config.
